## 六个阶段功能规划

### 阶段一：基础桌宠

> **目标**：一二/布布出现在桌面上，有动画、能互动

| 功能点 | 说明 | DyberPet 已有 | 需要做 |
|--------|------|:---:|:---:|
| 桌面显示 | 透明无边框置顶窗口，显示一二或布布 | ✅ | 配置角色素材 |
| 角色选择 | 启动时可选择一二或布布 | ⚠️ | 扩展角色切换逻辑 |
| 待机动画 | 站立、眨眼、偶尔伸懒腰等随机动作 | ✅ | 配置 act_conf.json |
| 点击互动 | 点击触发反馈动画（开心、害羞等）+ 气泡 | ✅ | 配置气泡文本 |
| 拖拽移动 | 鼠标拖拽角色移动到任意位置 | ✅ | 无需改动 |
| 右键菜单 | 右键弹出菜单（设置、切换角色、退出等） | ✅ | 扩展菜单项 |
| 状态栏 | 显示 HP/饱食度、好感度进度条 | ✅ | 可保留或简化 |

**阶段一产出**：一个能在桌面上自由移动、有基础动画的一二/布布桌宠。

### 阶段二：LLM 智能对话

> **目标**：桌宠接入大模型，有性格、会聊天

| 功能点 | 说明 | DyberPet 已有 | 需要做 |
|--------|------|:---:|:---:|
| LLM API 接入 | 对接 DeepSeek API（或其他兼容 OpenAI 格式的 API） | ❌ | **新增** `llm_client.py` |
| 聊天窗口 | 输入框 + 对话显示区，流式输出回复 | ❌ | **新增** `chat_window.py` |
| 人设 Prompt | 定义一二/布布的性格、语气、行为规则 | ❌ | **新增** `prompts/` 目录 |
| 情感识别 | 解析 LLM 回复中的情感标签，驱动对应动画 | ❌ | **新增** `emotion_parser.py` |
| 对话历史 | 保存最近 N 轮对话作为上下文 | ❌ | **新增** `chat_history.py` + SQLite |
| 长期记忆 | 用户偏好、重要事件存入 SQLite | ❌ | **新增** `memory_store.py` |
| API 设置面板 | 在设置中配置 API Key、模型、参数 | ❌ | 扩展 `BasicSettingUI.py` |
| 右键入口 | 右键菜单增加"聊天"选项 | ⚠️ | 扩展 `custom_roundmenu.py` |

**阶段二产出**：能对话、有性格、会记事的 AI 桌宠。

### 阶段三：待办事项 + 番茄计时

> **目标**：桌宠帮你管理日常任务，番茄钟专注计时

| 功能点 | 说明 | DyberPet 已有 | 需要做 |
|--------|------|:---:|:---:|
| 番茄钟倒计时 | 设置时长→开始专注→结束提醒 | ✅ `FocusPanel` | 扩展动画联动 |
| 专注模式 | 无番茄休息周期的连续计时 | ✅ `FocusPanel` | 同上 |
| 每日待办清单 | 添加/编辑/勾选/删除待办事项 | ✅ `TaskPanel` | 扩展任务提醒 |
| LLM 生成待办 | 对话中告诉一二"下午要交论文"，自动添加待办 | ❌ | **新增** `task_parser.py` |
| 到时提醒 | 待办截止/番茄结束 → 弹窗 + 动画 + 语音提醒 | ⚠️ | 扩展 `Notification.py` |
| 完成互动 | 勾选完成任务 → 一二开心蹦跳 + 鼓励对话 | ❌ | **新增** 完成动画触发逻辑 |
| 每日事件簿面板 | Dashboard 中查看/管理所有待办和计时 | ✅ `taskUI.py` | UI 微调适配一二布布风格 |

**阶段三产出**：能帮你管理时间、陪你专注工作的效率型桌宠。

### 阶段四：一二 ↔ 布布 WebSocket 通信

> **目标**：两台电脑的一二和布布可以实时对话

| 功能点 | 说明 | DyberPet 已有 | 需要做 |
|--------|------|:---:|:---:|
| WS 服务器 | FastAPI + websockets，管理连接和消息路由 | ❌ | **新增** `ws_server.py` |
| WS 客户端 | 桌宠内嵌 WebSocket 客户端，自动连接服务器 | ❌ | **新增** `ws_client.py` |
| 配对机制 | 一二端和布布端配对（房间号/邀请码） | ❌ | **新增** 配对逻辑 |
| 聊天气泡 | 收到对方消息 → 头顶显示气泡，3 秒后消失 | ⚠️ | 扩展 `DPDialogue` 添加自动消失计时 |
| 聊天记录 | 所有聊天内容存入 SQLite，可查看历史 | ❌ | **新增** `chat_log.py` |
| 在线状态 | 显示对方是否在线 | ❌ | **新增** 状态心跳 |
| 服务器部署 | WS 服务器可部署在本地或云服务器 | ❌ | **新增** Docker 配置 |

**通信协议示例**：

```json
{
  "type": "chat",
  "from": "yier",
  "to": "bubu", 
  "content": "布布你今天有没有想我！",
  "emotion": "excited",
  "timestamp": 1691145600
}
```

**消息流程**：

```
一二输入"想你了"
  → 一二端 WS Client 发送消息到服务器
  → 服务器转发给布布端
  → 布布桌宠头顶弹出气泡："一二说：想你了"（3秒消失）
  → 布布的 LLM 自动生成回复
  → 回复通过 WS 发回一二
```

**阶段四产出**：一二和布布可以在两台电脑上互相聊天。

### 阶段五：远程互动动作

> **目标**：一方可以触发另一方的动画和互动

| 功能点 | 说明 | DyberPet 已有 | 需要做 |
|--------|------|:---:|:---:|
| 送礼物 | 一方发送"礼物"指令 → 另一方播放"收到礼物"动画 + 气泡 | ❌ | **新增** 礼物协议 + 动画触发 |
| 动作指令 | 发送"戳一下""摸摸头""跳舞"等 → 对方播放对应动画 | ❌ | **新增** `action_trigger.py` |
| 互动道具 | 预设道具列表（花、零食、小纸条），发送后对方显示对应动画 | ❌ | **新增** `gift_system.py` |
| 互动记录 | 保存互动历史（谁在什么时候做了什么） | ❌ | **新增** `interaction_log.py` |

**协议示例**：

```json
{
  "type": "action",
  "from": "yier",
  "to": "bubu",
  "action": "send_gift",
  "gift": "flower",
  "message": "送你一朵小花花~"
}
```

```
一二点击"送花"
  → 一二端播放"送出"动画
  → WS 发送 action 指令
  → 布布端收到 → 播放"收到花"动画 + 气泡"一二送了你一朵花！"
  → 布布 LLM 自动回复"谢谢一二~"
  → 回复通过 WS 发回一二
```

**阶段五产出**：一二和布布可以远程互动，送礼物、戳一戳、一起跳舞。

### 阶段六：移动端 APP

> **目标**：手机上可以和一二/布布聊天、查看和管理待办

| 功能点 | 说明 | 技术方案 |
|--------|------|---------|
| 登录配对 | 扫码或输入配对码连接到自己的桌宠 | Flutter + WS |
| 文字聊天 | 手机上发消息 → 桌宠 LLM 回复 → 显示在手机上 | Flutter 聊天 UI |
| 待办查看 | 查看桌面端同步过来的待办事项 | 列表 UI |
| 待办管理 | 添加/编辑/删除待办，同步到桌面端 | WS 同步 |
| 提醒推送 | 待办到期时手机收到推送通知 | FCM/APNs |
| 聊天记录 | 查看一二 ↔ 布布的历史聊天记录 | SQLite 本地缓存 |

**阶段六产出**：一个轻量级移动端 APP，核心只有聊天 + 待办。
