# 脂质组学论文 — 实验流程对比汇总

> 生成日期：2026-07-18
> 对比基准：导师流程（CD → 差异峰 → 靶向 MS/MS → LipidSearch）

---

## 表 1：导师流程 vs Bonicelli et al. (2022) — ForensOMICS

| 对比维度 | 导师流程 | 论文流程（Bonicelli 2022, eLife） |
|----------|---------|----------------------------------|
| **样品类型** | 通用（环境/生物样品） | 人胫骨（生前 vs 死后 219/790/834/872 天，n=24） |
| **前处理** | 脂质提取（液液萃取，手动操作） | 代谢+脂质+蛋白三组学分别提取 |
| **采集模式** | DDA 非靶向 → 靶向 MS/MS（两次跑样） | AcquieX DDA + inclusion list（一次正式跑样 + QC 预跑） |
| **Inclusion list 来源** | CD 差异峰列表（统计显著） | Pooled QC 全峰列表（所有可检测物质） |
| **Inclusion list 生成** | 人工整理 | 软件自动 |
| **跑样次数** | 2 次正式跑 | 1 次正式跑 + 1 次 QC 预跑（~1小时） |
| **总进样量（N=30）** | ~66 针 | ~35 针 |
| **峰检测软件** | CD | CD 3.2 |
| **CD 参数** | 未具体说明 | 10 ppm, 0.3 min 对齐, S/N≥3, 最小强度 10⁶ |
| **初步鉴定** | CD 自带库（mzCloud/ChemSpider）搜索差异峰 m/z | mzCloud MS2 匹配，相似度≥50% |
| **脂质鉴定软件** | LipidSearch | LipidSearch 4 |
| **LipidSearch 参数** | 未具体说明 | HCD 库, 母离子 5 ppm, 碎片 10 ppm, m-score≥5, Grade A/B only |
| **差异分析** | 对照组 vs 处理组（fold change + p-value） | Kruskal-Wallis + PLS-DA + DIABLO 多组学整合 |
| **QC 标准** | 未具体说明 | QC 间 RSD<15%, 峰保留 RSD≤25% |
| **人工工作量** | 高（前处理 + inclusion list 编写 + 两次跑样） | 中（前处理 + QC 配制，但省一次正式跑样） |
| **MS2 覆盖范围** | 仅差异峰 | 所有峰（QC 中出现的全部打） |
| **文献链接** | — | https://doi.org/10.7554/eLife.83658 |

## 表 2：导师流程 vs Deshpande et al. (2025) — 单细胞脂质组学

| 对比维度 | 导师流程 | 论文流程（Deshpande 2025, Thermo Fisher 海报） |
|----------|---------|-----------------------------------------------|
| **样品类型** | 通用 | 单细胞（RK13 / Vero 细胞系） |
| **前处理** | 脂质提取（液液萃取） | 单细胞分选 → 自动化微量前处理 |
| **采集模式** | DDA → 靶向 MS/MS（两次跑样） | 非靶向 DDA（Orbitrap Ascend Tribrid）→ 靶向 PRM（Stellar MS） |
| **Inclusion list 来源** | CD 差异峰列表 | CD 3.4 + LipidSearch 鉴定结果 → 864 脂质 inclusion list |
| **Inclusion list 生成** | 人工整理 | 软件辅助导出 |
| **跑样次数** | 2 次 | 2 次（DDA 探索 + PRM 靶向），与导师流程一致 |
| **第一次跑** | 所有样品 → DDA | 批量细胞提取 → Orbitrap Ascend DDA |
| **第二次跑** | 靶向 MS/MS | 单细胞 → Stellar MS 靶向 PRM（864 脂质） |
| **软件工具** | CD + LipidSearch | CD 3.4 + LipidSearch + Skyline |
| **CD 版本** | 未指定 | 3.4（LipidSearch 已集成为内置节点） |
| **差异分析** | fold change + p-value | PCA 区分单细胞类型 |
| **QC 标准** | 未具体说明 | 内标归一化 |
| **特殊技术** | 无 | 多级 MSⁿ 碎裂提升同分异构体区分；AcquireX 迭代采集 |
| **检出限** | 常规 | 皮克级（单细胞水平） |
| **人工工作量** | 高 | 高（单细胞分选 + inclusion list 864 条 + 两次跑样） |
| **与导师流程的相似度** | — | **高度一致**：DDA 初筛 → 生成 list → 靶向重跑 → LipidSearch |
| **文献链接** | — | https://lcms.labrulez.com/paper/32146 |

## 表 4：导师流程 vs Marine Drugs (2024) — 北极硅藻

| 对比维度 | 导师流程 | 论文流程（Marine Drugs 2024） |
|----------|---------|------------------------------|
| **样品类型** | 通用 | 北极硅藻（海洋环境样品） |
| **实验变量** | 对照组 vs 处理组 | 不同光照条件 |
| **前处理** | 脂质提取 | 硅藻培养 → 色素提取 + 脂质提取 |
| **采集模式** | DDA → 靶向 MS/MS | LC-Orbitrap MS/MS（DDA） |
| **软件组合策略** | 只针对脂质 | **双软件互补**：LipidSearch 4.2 做脂质鉴定定量 + CD 3.3 做色素分析 |
| **CD 的角色** | 全部脂质数据的处理 | 处理色素数据（用自定义 mzVault 色素数据库，>70% 匹配分数，<5 ppm 质量精度） |
| **LipidSearch 的角色** | 脂质深度鉴定 | 脂质鉴定和定量 |
| **差异分析** | fold change + p-value | 不同光照条件下脂质和色素变化比较 |
| **自定义数据库** | 无 | 有（mzVault 色素数据库） |
| **与导师流程的关系** | — | 验证了 CD + LipidSearch 在**环境样品**中的可行性；且展示了一个思路——CD 不限于做脂质，自定义库可拓展到色素、污染物等 |
| **文献链接** | — | SINTEF 开放获取 (marinedrugs-22-00067) |

## 表 5：导师流程 vs Soil_Lipidomics (2024-2025) — 土壤脂质组学

| 对比维度 | 导师流程 | 论文/项目流程（flysamc, GitHub 开源） |
|----------|---------|--------------------------------------|
| **样品类型** | 通用 | 冻干土壤（环境样品，与你的课题方向最相关） |
| **实验设计** | 对照组 vs 处理组 | ClimGrass 实验：气候（增温）× 干旱对土壤脂质的影响 |
| **前处理** | 脂质提取（液液萃取） | 冻干土壤 → 13 类同位素内标添加 → NIST SRM 1950 血浆作参考 |
| **采集模式** | DDA → 靶向 MS/MS | LC-Orbitrap MS/MS（DDA） |
| **软件工具** | CD + LipidSearch | **多工具并行**：LipidSearch 5（主鉴定）+ SIRIUS 5（理论碎片预测）+ GNPS（分子网络 + 在线谱库）+ Skyline（靶向定量） |
| **鉴定策略** | 单一软件（LipidSearch） | **三工具并行**：三个工具的鉴定结果取并集 → 提高覆盖度和置信度 |
| **差异分析** | CD 内置统计 | 多变量统计（PCA, PLS-DA 等）→ 生物标志物发现 |
| **QC 方案** | 未具体说明 | LipidQC + pooled QC + 外部标准品校正 + 内标回收率评估（比常规 QC 更严格） |
| **开源/闭源** | 闭源（赛默飞付费） | 工具组合（LipidSearch 闭源 + SIRIUS 免费 + GNPS 免费 + Skyline 免费） |
| **与导师流程的关系** | — | 导师流程是**子集**——LipidSearch 是 Soil_Lipidomics 的主鉴定工具之一；这个项目证明在环境（土壤）脂质组学中 CD+LipidSearch 是可行的，但多工具互补效果更好 |
| **文献链接** | — | https://github.com/flysamc/Soil_Lipidomics |

## 总结对比：五种流程的核心差异

| | 导师 | Bonicelli 2022 | Deshpande #2 单细胞 | Deshpande #3 CD 3.4 | Marine Drugs 2024 | Soil_Lipidomics |
|---|---|---|---|---|---|---|
| **跑样次数** | 2 | 1（AcquieX） | 2 | —（技术报告） | 1（DDA） | 1（DDA） |
| **Inclusion list** | 差异峰（人工） | Pooled QC（自动） | 864 脂质列表 | — | — | — |
| **CD 用途** | 全部脂质 | 代谢组 | 脂质初筛 | 脂质一站式 | 色素 | 未使用 |
| **LipidSearch** | 脂质鉴定 | 脂质鉴定 | 脂质鉴定 | 内置于 CD 3.4 | 脂质鉴定 | 主鉴定工具 |
| **额外工具** | 无 | 蛋白质组学软件 | Skyline | 无 | 自定义 mzVault | SIRIUS + GNPS + Skyline |
| **鉴定策略** | 单一工具 | 多组学整合 | 软件组合 | 单一工具（集成） | 双软件互补 | 多工具并行 |
| **最适用场景** | 通用脂质组学 | 多组学研究 | 高灵敏度靶向 | 赛默飞用户 | 环境+自定义库 | 土壤环境脂质组学 |
| **人工量** | 高 | 中 | 高 | 低 | 中 | 中 |

## 给你的最佳实践建议

```
根据以上五篇论文的对比，推荐流程（取各家所长）：

【如果你们实验室是赛默飞 Orbitrap + 有 CD 3.4】
  → 升级到 CD 3.4（LipidSearch 已集成，省去软件切换）
  → 参考 AcquieX 思路：QC 预跑生成 inclusion list → 一次 DDA 全覆盖
  → 参考 Soil_Lipidomics：增加 SIRIUS + GNPS 免费工具做补充鉴定

【如果仪器不支持 AcquieX / CD 版本较老】
  → 导师流程完全可行：DDA 初筛 → 靶向重跑
  → 但建议先跑 QC 生成 inclusion list（手工），不限于差异峰
  → 参考 Marine Drugs：CD + LipidSearch + 考虑自定义数据库

【最省人力（如果你样品量大）】
  → 推动自动化前处理（参考 2024 多篇自动化综述）
  → 或改用 DIA 模式，省去 inclusion list 和第二次跑样
```
