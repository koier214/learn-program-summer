# 脂质组学 CD + LipidSearch 工作流程 — 问题梳理

> 对话日期：2026-07-18
> 主题：基于导师组会讲解的脂质组学数据分析流程（Compound Discoverer → 靶向 MS/MS → LipidSearch），逐层追问基础概念与流程逻辑

---

## 问题 1：CD → LipidSearch 这个流程是否可行？是否"传统"？

**解决**：
- 该流程**可行且仍然是主流**，是赛默飞（Thermo Fisher）生态系统的标准脂质组学方法
- "传统"不等于"错误"——它经过大量文献验证，审稿人认可
- 但"传统"的代价确实存在：样品前处理（液液萃取）人工成本高、DDA 模式可能遗漏低丰度差异峰、需要人工编写 inclusion list
- CD 3.4（2025 年 3 月发布）已将 LipidSearch 集成为内置节点，减少软件间切换
- 替代方案：MS-DIAL（免费开源）+ LipiDex；或 DIA（数据非依赖采集）一次覆盖所有离子

**关键文献**：
- Bonicelli et al. (2022), *eLife* — CD 3.2 + LipidSearch 4 完整双软件工作流程
- Deshpande et al. (2025), Thermo Fisher Poster — CD 3.4 整合 LipidSearch 节点
- Aigensberger et al. (2025) — CD vs MS-DIAL vs XCMS vs MZmine 对比（CD 在高基线峰上表现不如 MS-DIAL）

---

## 问题 2：一级数据（MS1）是什么？哪来的？

**解决**：
- MS1 = 质谱仪对样品中所有离子进行全扫描（Full Scan）得到的数据
- 数据来源：样品经 LC-MS 分析，色谱柱先按保留时间（RT）分离物质，质谱仪再测量每个时间点流出的离子
- MS1 数据包含三个维度：**RT（保留时间）+ m/z（质荷比）+ Intensity（信号强度）**
- 一个样品跑 30 分钟，可检测到几千到上万个"峰"
- "找差异峰"是样品组之间的统计比较（对照组 vs 处理组的 Intensity 比较），与标准库无关

---

## 问题 3：色谱柱为什么能按时间分开物质？

**解决**：
- 色谱柱 = 不锈钢管内填充微米级颗粒，颗粒表面涂有化学涂层（固定相，如 C18）
- 分离原理：不同分子和涂层的"粘性"不同 → 亲和力强的分子被吸附更久（出来晚），亲和力弱的分子滑过更快（出来早）
- RT = 分子从进柱到出柱的时间，由 LC 部分决定（非质谱仪测得）
- C18 涂层（疏水性强）是脂质组学最常用类型——脂质碳链越长、双键越少越疏水 → RT 越大

---

## 问题 4：同一 RT 流出多个物质怎么办？（共流出问题）

**解决**：
- RT 相同但 m/z 不同 → 质谱仪可直接区分（质量维度）
- RT 相同且 m/z 相同（同分异构体，如 PC(16:0/18:1) vs PC(18:1/16:0)）→ MS1 无法区分，必须靠 MS/MS 碎片谱
- 手性异构体（极端情况）→ 需特殊手性色谱柱或离子淌度（IMS）
- 形成层层递进的分离鉴定策略：色谱 → 质量精度 → 碎片谱 → 更高级技术

---

## 问题 5：RT + m/z 能否确定一个物质？Intensity 的作用？

**解决**：
- RT + m/z 不能完全确定物质，但能大幅缩小候选范围
- RT 与分子疏水性高度相关，可用来排除不符合色谱行为的候选物
- RT 不能用于数据库搜索的原因：RT 随色谱条件（柱子类型、流动相）变化，不同实验室不可直接比较
- Intensity = 检测器接收到的离子数量 → 反映物质浓度 → 是定量比较的基础
- 差异分析逻辑：同一峰在两组间 Intensity 有显著差异 → 该物质可能与实验变量有关

---

## 问题 6：不同组（对照组/处理组）怎么跑？一起还是分开？

**解决**：
- 每个样品独立进样，每次跑完整的 LC-MS 分析（如 30 分钟）
- 一个批次内顺序跑：Blank → QC（稳定仪器）→ 对照组 1/2/3 → QC（监测漂移）→ 处理组 1/2/3 → QC → Blank
- 质谱仪同一时间只能分析一个样品
- CD 软件跑完后将所有样品的峰对齐，再做组间统计比较

---

## 问题 7：峰对齐是什么？为什么需要？

**解决**：
- 峰对齐 = 把不同样品中代表同一物质的峰识别出来，归入同一峰组
- 必要性：同一物质在不同样品中 RT 会有微小偏移（柱子老化、温度波动 → ±0.1-0.3 min）
- 对齐依据：m/z（±5 ppm）+ RT（±0.3 min），两个维度同时满足 → 判定为同一个峰
- 不对齐 → 无法做组间 Intensitiy 比较 → 差异分析无法进行
- 一次 CD Study = 多个 .RAW 文件 → 多文件才能进行对齐

---

## 问题 8：.RAW 文件包含什么？

**解决**：
- 一个 .RAW 文件 = 一个样品的一次 LC-MS 分析数据
- 内容：整个分析过程中每轮扫描的记录
  - MS1 扫描：RT + 所有 m/z + Intensity
  - MS2 扫描：RT + 母离子 m/z + 碎片 m/z + 碎片 Intensity
- **一次 DDA 实验同时获得 MS1 和 MS2**，但不是所有峰都有 MS2（DDA 只选信号最强的 Top 10/20）
- 一个 .RAW 文件只包含一个样品，不包含分组信息（分组在 CD 软件内手动设置）

---

## 问题 9：扫描循环（Scan Cycle）是什么？

**解决**：
- 质谱仪在约 1 秒内完成一轮循环：1 次 MS1 全扫描 + N 次 MS2（打碎最强 N 个离子）
- 整个分析过程（30 min）= 约 1000-2000 轮循环
- 每个扫描有独立的扫描编号和时间戳，全部记录在 .RAW 文件中

---

## 问题 10：DDA（数据依赖采集）的工作机制

**解决**：
- DDA = 非靶向 MS/MS 采集模式：仪器自动选信号最强的 Top 10/20 个离子打碎
- Top N 可调：N 越大覆盖面越广，但每个离子的 MS2 扫描时间越短 → 谱图质量越低（信噪比差）
- Top 10 是大多数实验室的经验平衡点
- DDA 不会"结束"——整个采集过程中无限循环
- DDA 结果：所有峰的 MS1 + 部分峰的 MS2（但低丰度峰可能遗漏）
- DDA ≠ 全扫描（Full Scan）；DDA 包含 MS1 + 选择性 MS2

---

## 问题 11：MS/MS（串联质谱）是什么？

**解决**：
- MS1 → 选出目标母离子 → 碰撞室（充氮气）碎裂 → MS2 测量碎片离子的 m/z + Intensity
- 碎片谱 = 分子的"指纹"，用于结构鉴定
- 碎裂发生在**质谱仪内部的碰撞室**，与色谱柱无关
- 二级数据库：LipidSearch 包含 >170 万种脂质的理论预测碎片（in silico fragmentation），用于匹配实测碎片谱

---

## 问题 12：初步鉴定（CD）和深度鉴定（LipidSearch）的分工

**解决**：
- CD 初步鉴定：差异峰精确 m/z → 搜索 mzCloud/ChemSpider 等数据库 → 候选化合物列表（仅靠质量数，置信度有限）
- LipidSearch 深度鉴定：碎片谱 → 匹配脂质专用理论碎片库 → Grade A/B/C/D 分级
  - Grade A = 脂质类别 + 两条脂肪酸链完全确定
  - Grade B = 脂质类别 + 一条脂肪酸链确定
  - Grade C/D = 更低置信度
- 之所以分两步：脂质的碎片规律特殊，通用数据库覆盖不全，需专用软件

---

## 问题 13：QC（质控样品）是什么？

**解决**：
- QC = 所有待分析样品各取等量混合 → 理论上包含所有物质
- 作用：在批次不同时间点多次跑 QC → 监测仪器信号漂移 → 用于数据校正（QC 归一化）
- 区分"生物学差异"和"仪器漂移"

---

## 问题 14：为什么要"靶向重跑"第二次？

**解决**：
- 第一次 DDA 的 MS2 覆盖是概率性的（按信号强度选）→ 低丰度差异峰大概率遗漏
- Inclusion list = 人工编写的"必须碎裂名单"（m/z + RT + 时间窗口），在采集软件（如 Xcalibur）中加载
- 第二次跑：同批样品再跑 LC-MS（靶向模式），质谱仪在指定 RT 范围内强制碎裂 list 上的离子
- 如果第一次 DDA 中某差异峰已有高质量 MS2 → 直接用，不需要重跑
- 实际比例：简单样品 DDA 可覆盖 70-80%，复杂样品（土壤/血浆）可能只覆盖 30-50%

---

## 问题 15："缺失 MS2"还能在差异峰列表里？（逻辑澄清）

**解决**：
- 不矛盾——差异峰的"存在"和"身份"由不同数据判断
- MS1（Intensity 比较）→ 知道"某个物质变了" → 进入差异峰列表
- MS2（碎片匹配）→ 知道"这个物质是谁" → MS2 缺失时无法鉴定
- 一个峰可以同时满足：在差异峰列表里（有 MS1 证据）+ 缺少 MS2 数据（DDA 没选它打碎）

---

## 问题 16：脂质命名 PC(16:0/18:2) 的含义

**解决**：
- PC = 磷脂酰胆碱（Phosphatidylcholine），脂质类别
- 16:0 = sn-1 位脂肪酸：16 个碳，0 个双键（棕榈酸，饱和）
- 18:2 = sn-2 位脂肪酸：18 个碳，2 个双键（亚油酸，不饱和）
- 结构类比：甘油骨架 = 有三个挂钩的衣架 → sn-1/sn-2 挂两条脂肪酸尾巴 + sn-3 挂磷酸胆碱头基 → 整体呈蝌蚪形（亲水头 + 疏水尾）
- 双键数越多链越弯 → 影响细胞膜流动性 → 是环境胁迫研究的生物学基础

## 核心流程总图

```
第一轮（探索）：
  所有样品 → LC-MS（DDA 非靶向模式）→ 多个 .RAW 文件（含 MS1 + 部分 MS2）
     ↓
  CD 处理 → 峰检测 → 峰对齐 → 差异分析 → 差异峰列表
     ↓
  检查差异峰 MS2 覆盖情况
     ├── 有高质量 MS2 → 直接 LipidSearch 鉴定
     └── 缺 MS2/质量差 → 整理成 inclusion list

第二轮（鉴定）：
  同一批样品 → LC-MS（靶向 MS/MS + inclusion list）→ 新 .RAW 文件
     ↓
  差异峰获得全部高质量 MS2
     ↓
  LipidSearch → 碎片谱匹配脂质数据库 → Grade A/B/C/D 鉴定结果

目的达成：
  差异峰从 "m/z=758.5694 未知物" → 确认为 "PC(16:0/18:2), Grade A, 处理组升高 3.5 倍"
```

## 关键概念速查表

| 术语 | 含义 | 由哪个仪器/软件产生 |
|------|------|-------------------|
| RT | 保留时间，分子从进柱到出柱的时间 | 色谱（LC） |
| m/z | 质荷比，分子的质量除以电荷 | 质谱（MS） |
| Intensity | 信号强度，到达检测器的离子数量 | 质谱（MS） |
| MS1 | 一级质谱，全扫描所有离子 | 质谱（MS） |
| MS2/MS/MS | 二级/串联质谱，碎裂后测碎片 | 质谱（碰撞室+第二级检测器） |
| DDA | 数据依赖采集，自动选最强离子打碎 | 质谱采集方法 |
| .RAW | 原始数据文件，含 MS1+MS2 | LC-MS 仪器输出 |
| CD | Compound Discoverer，数据处理软件 | 赛默飞软件 |
| LipidSearch | 脂质专用鉴定软件 | 赛默飞软件 |
| Inclusion list | 靶向碎裂名单 | 人工编写，质谱采集软件加载 |
| QC | 质控样品，所有样品混合 | 人工配制 |
