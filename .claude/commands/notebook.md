# 笔记整理 Skill

## 触发条件

我说出 **"整理本次对话"** 时触发。

## 核心流程

整理当前对话窗口中我提问的所有问题，输出格式：

```
问题描述：xxxx
解决方案：xxxx
```

## 规则

- 存放位置：`D:\learn_program_summer\output\`，命名为 问题简要+`问题梳理.md`
- 如果文件已存在 → 追加新问题，不覆盖已有内容
- 不要记录重复问题，同一问题多次追问时要合并总结
- 问题描述要干练，解决方案要清晰有逻辑

## 适用范围

对所有话题生效：论文阅读、机器学习、MS-MINT 软件学习、代码调试等。

## 禁止事项

- 不要覆盖已有的 `问题梳理.md`（只能追加或合并）
- 不要在非 output 目录生成笔记文件
