## 核心原则

### 1. 一次只讲一个概念
不要一次性倒给我一堆知识点。每次讲一个概念，按"概念 → 为什么重要 → 环境例子 → 代码演示(可选)"的顺序。

### 2. 每步必答三问（What / Why / How）
讲每个概念时，必须回答：
- **What**：这个概念是什么？（一句话定义）
- **Why**：为什么需要这个概念？（因果链：没有它会怎样？）
- **How**：怎么用？（在环境预测中具体怎么操作）

### 3. 术语解释格式
首次出现专业术语时，遵循 CLAUDE.md 规则 #2 的四段式格式（📚📖🌰🔗）。

### 4. 知识难度分级
每个概念标注难度，让我有心理预期：

| 难度 | 标签 | 说明 |
|------|------|------|
| 入门 | 🟢 | 不需要数学推导，直觉理解即可 |
| 进阶 | 🟡 | 需要高中/本科数学基础 |
| 深入 | 🔴 | 需要推导公式，可暂时跳过 |

### 5. 数学公式处理
遵循 CLAUDE.md 规则 #8：公式用来理解"它衡量了什么"，先直觉再公式，复杂推导可标注"先记住结论，用到再回看"。

## 关键概念速查表（持续更新）

> 以下是学习过程中会逐一讲解的核心概念。每学完一个打勾 ☑️

### 基础层
- [ ] **机器学习(Machine Learning)**：让计算机从数据中自动学习规律，而不是人工编写规则
- [ ] **深度学习(Deep Learning)**：机器学习的一种，用多层神经网络自动提取特征
- [ ] **监督学习(Supervised Learning)**：给数据打标签，让模型学"输入→输出"的映射
- [ ] **无监督学习(Unsupervised Learning)**：数据没有标签，让模型自己发现结构/模式
- [ ] **回归(Regression)**：预测连续数值（如污染物浓度 = 3.7 μg/L）
- [ ] **分类(Classification)**：预测离散类别（如有毒/无毒、高/中/低风险）

### 数据层
- [ ] **特征(Feature)**：输入给模型的每个变量（如分子量、logP、氢键供体数）
- [ ] **标签(Label)**：模型要预测的目标值（如 LC50、生物降解率）
- [ ] **训练集/验证集/测试集**：数据的三次分割，分别用于"学习"、"调参"、"最终检验"
- [ ] **数据标准化(Normalization)**：把不同量纲的特征缩放到同一尺度
- [ ] **SMILES**：用字符串表示分子结构（如 `CCO` = 乙醇）
- [ ] **分子指纹(Molecular Fingerprint)**：把分子结构编码为固定长度的二进制向量
- [ ] **分子图(Molecular Graph)**：用图表示分子（原子=节点，化学键=边）
- [ ] **QSAR(定量构效关系)**：用数学模型描述分子结构与其活性/性质的关系

### 模型层
- [ ] **神经网络(Neural Network)**：多层互相连接的"神经元"，模拟人脑的信息处理
- [ ] **损失函数(Loss Function)**：衡量"预测值"和"真实值"差多少
- [ ] **优化器(Optimizer)**：调整模型参数让损失越来越小的算法
- [ ] **梯度下降(Gradient Descent)**：沿着"最陡的下坡方向"更新参数的策略
- [ ] **学习率(Learning Rate)**：每次更新参数的步长
- [ ] **过拟合(Overfitting)**：模型死记硬背训练数据，碰到新数据就蒙了
- [ ] **正则化(Regularization)**：给模型加约束，防止过拟合
- [ ] **Epoch / Batch / Iteration**：训练的三个"循环层级"

### 模型层（进阶）
- [ ] **全连接网络(Fully Connected Network)**：最基础的神经网络，每层神经元和下一层全部相连
- [ ] **CNN(卷积神经网络)**：擅长处理网格化数据（图像、光谱）
- [ ] **RNN/LSTM(循环神经网络)**：擅长处理序列数据（时间序列监测数据）
- [ ] **GNN(图神经网络)**：擅长处理图结构数据（分子！原子=节点，化学键=边）
- [ ] **随机森林(Random Forest)**：非深度学习方法，用多棵决策树投票，适合小数据集
- [ ] **迁移学习(Transfer Learning)**：拿别人训好的大模型，微调后用于自己的任务

### 环境应用层
- [ ] **分子性质预测**：给定分子结构 → 预测 logP、溶解度、沸点等理化性质
- [ ] **毒性预测**：给定分子结构 → 预测 LD50、致突变性、内分泌干扰活性等
- [ ] **暴露组分析**：从质谱数据中鉴定和定量环境污染物
- [ ] **环境监测预测**：用历史监测数据预测未来污染物浓度趋势

## 通用思路：环境 DL 项目的标准 pipeline

当我和你讨论一个环境预测项目时，我会按以下框架来组织思路：

```
┌──────────────────────────────────────────────────┐
│  1. 问题定义                                      │
│  ├─ 要预测什么？（回归/分类？单任务/多任务？）       │
│  └─ 为什么 DL/ML 比传统方法好？                    │
├──────────────────────────────────────────────────┤
│  2. 数据获取                                      │
│  ├─ 公开数据库：PubChem, ToxCast, CompTox, QSAR  │
│  ├─ 实验数据：自己的 LC-MS/GC-MS 数据              │
│  └─ 数据量评估：够不够训练深度学习模型？             │
├──────────────────────────────────────────────────┤
│  3. 分子表征（把化学变成数学）                      │
│  ├─ 传统方法：分子指纹 (Morgan/ECFP, MACCS)       │
│  ├─ 深度学习方法：图神经网络自动学习表征            │
│  └─ 选择依据：数据量 + 任务复杂度                  │
├──────────────────────────────────────────────────┤
│  4. 模型选择                                      │
│  ├─ 小数据 (<1000) → 随机森林, XGBoost           │
│  ├─ 中数据 (1k-10k) → 全连接网络 + 分子指纹        │
│  ├─ 大数据 (>10k) → GNN, Transformer             │
│  └─ 几乎没有数据 → 迁移学习 / 预训练模型           │
├──────────────────────────────────────────────────┤
│  5. 训练与评估                                     │
│  ├─ 划分：训练集 70% / 验证集 15% / 测试集 15%     │
│  ├─ 评估指标：R², RMSE (回归), AUC, F1 (分类)     │
│  └─ 交叉验证确保结果稳定                           │
├──────────────────────────────────────────────────┤
│  6. 模型解释                                      │
│  ├─ 特征重要性：哪些分子结构贡献最大？              │
│  ├─ SHAP 值：具体到一个分子，哪个官能团导致预测结果  │
│  └─ 解释 = 发论文的关键！                         │
└──────────────────────────────────────────────────┘
```

## 目录结构建议

当你要做一个环境预测项目时，按以下结构组织代码：

```
deepLearning/
├── {项目名}/                    # 每个项目一个子目录
│   ├── data/
│   │   ├── raw/                 # 原始数据（只读！）
│   │   └── processed/           # 预处理后的数据
│   ├── notebooks/               # Jupyter Notebook（探索性分析）
│   ├── src/
│   │   ├── data_loader.py       # 数据加载
│   │   ├── featurizer.py        # 分子表征（SMILES→分子指纹/图）
│   │   ├── model.py             # 模型定义
│   │   ├── train.py             # 训练脚本
│   │   └── evaluate.py          # 评估脚本
│   ├── checkpoints/             # 保存的模型权重
│   ├── outputs/                 # 预测结果、图表
│   └── README.md                # 项目说明（问题、数据来源、结论）
├── linearModel.py               # 已有的线性模型 demo
├── train.py                     # 已有的训练脚本
└── predict.py                   # 已有的预测脚本
```

> 💡 **当前状态**：你已经有了基础的 `linearModel.py`、`train.py`、`predict.py`，这是阶段4"经典模型"中线性回归的 practise。后续学习可以在此基础上扩展。
